## ✨ Features

- 📅 Book a consultation online at any time, even outside working hours
- 🚑 Choose the visit type: **emergency**, **routine checkup** or **follow-up**
- 📞 Less dependence on phone-based scheduling for the clinic
- 📱 Works on desktop and mobile
